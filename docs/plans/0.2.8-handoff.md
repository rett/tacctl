# tacctl 0.2.8 handoff (2026-10-13)

Read `docs/plans/backlog.md` section 0 (the roadmap) and
`docs/plans/0.2.9-rollout-plan.md` (the next release) with this note. The
lab results of this release are in `docs/plans/0.2.8-lab.md`.

## State

0.2.8 is built and not released. The work is on `feature/docs-layout`
(from `develop`), committed and not pushed. The CHANGELOG
`## 0.2.8 (unreleased)` lists it, numbered:

- the documentation as a tree of topic pages under `docs/`, `README.md` a
  quick start and an index, the man page condensed;
- tacquito patch 0003 (`0003-authen-log-addresses.patch`) names the client's
  address and port on the authentication lines; `ssh` audit lines carry
  `from=`;
- `install` and `upgrade` no longer copy the README into `/etc/tacquito`;
- device facts: the pull records the release, model and serial of each
  device; `device show`, a `RELEASE` column of `device config list`;
- the first row of the version-gate table (Junos `system login idle-timeout`
  from 16.1; per class before it) used by the walkthrough;
- the IOS blocks: the default `clock timezone` reads as present, the report's
  not-checked note is for NTP key lines only, the restore point's note is for
  the `archive config` form only, and the VRF forms and the `informs` host
  kind are managed, a host being identified by address, vrf, kind, udp-port
  and community.

## What remains before the release

- The whole-branch gates on the merged tree: the container matrix
  (`tests/containers/run-all.sh`, the `hosts` case at least once for the
  installer change), the differential corpus against 0.2.7 with
  `@known 0.2.8 item N` markers where output changed, every bats file, the
  final whole-diff review.
- The `fresh` container run checks that `install` writes no README into the
  daemon's directory.
- Not run on a device: the system block's NTP key lines, another banner
  delimiter, the vrf forms on IOS 12.4 (`ip vrf` there), the `archive config`
  form of the restore point.
- Decided: on IOS 12.4 a block's `ntp server H version 3` is stored without
  the option; a device in the IOS 12.x syntax is rendered and compared
  without `version 3` (`blocks.IOSDialect`), keyed on `Request.Legacy`.
- The release (`docs/releasing.md`) happens only when the user says so.
