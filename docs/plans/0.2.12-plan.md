# tacctl 0.2.12 plan (2026-10-15)

Read `0.2.12-handoff.md` (state, working rules) first. Decisions continue
the numbering of `0.2.11-plan.md` (D152-D158).

## 1. Scope

A small-follow-ups release: the items the 0.2.11 reviews filed as "later",
each its own gated unit with its CHANGELOG item, man page and docs page
where it is visible to a user. No state-format change, no new device write
path, no new credential.

|---|---|---|

| 12.2 | `config validate` warns for keys that name a group or scope the store does not have | yes |
| 12.3 | The tier notes come from a field on the rule, not a second list | no (the man TIERS block must not change) |
| 12.4 | A re-run of `tacctl install` takes the apply lock | yes (known limit of 0.2.11 removed) |
| 12.5 | A Go test job in CI | no |
| 12.6 | The `internal/cli` run is measured and its slowest tests cut or split | no |

The release was widened on 2026-10-15 ("substantial"); built in the same
way:

| WP | Item | User-visible |
|---|---|---|
| 12.7 | Review fixes: family names from the store in `config get` completion, no space after a prefix, an accurate Ctrl-C message for `install` and `upgrade`, backlog hygiene | yes |

## 2. Direction (decided 2026-10-15)

Every tacctl operation is started by a person at the time it runs. tacctl
holds no credential for a device and runs no operation on a schedule, and
none is planned. The roadmap items that needed one are dropped: device
accounts and break-glass rotation, a service account, unattended drift
detection, the break-glass users block with a stored hash, and a timer that
releases a hold. A person who wants a periodic report runs `device config
diff --pull` themselves, with their own password.

The line is drawn at what an operation does: refreshing local data (the
seen cache, from a scan that reads no credential and changes no device or
configuration) at the start of an interactive session is a person's own
sign-in at work and is within the rule. A device read or write, a stored
credential, or anything that runs with nobody signed in is not.

## 3. Decisions

| # | Decision | Status |
|---|---|---|
| D159 | The session-start background scan of 0.2.11 (`device scan --if-stale --quiet`, detached, from an interactive console or shell, at most every five minutes) stays as built: it runs because a person signed in, reads no credential, and writes only the seen cache. Nothing changes. | decided |
| D160 | 12.1: the completion words are the schema's keys and family prefixes (no space after a prefix); once a prefix is typed, the groups or scopes of the store follow, from the same live-name bridge the other kinds use. A free-text family (`listeners.`, `blocks_device.`, `breakglass_hold.`) offers its prefix only. | built |
| D161 | 12.2: a warning, never an error, for each of `privileges.<g>`, `commands.<g>`, `tier.<g>`, `junos.<g>.*` naming a group the store lacks and each of `snmp_scope.<s>.*`, `breakglass_scope.<s>.*`, `blocks.<s>.*`, `cisco.source_interface.<s>`, `netconf.<s>` naming a missing scope; one `Orphan settings:` line per key, which says to remove it from `tacctl.yaml` by hand (there is no `config unset`). Built-in group names are never orphans. | built |
| D162 | 12.3: a `Note` field on the sudo/tier rule row; the TIERS man block and the `help` notes are generated from it; the existing test that fails for a narrower row without a note stays. | proposed |
| D163 | 12.4: `tacctl install` takes the apply lock around the writes of `tacctl.yaml` and `store.yaml` and the restarts, as `upgrade` does after its exec; it waits and says so as the other commands do; a Ctrl-C while it waits says that the store, `tacctl.yaml` and the services were not changed and to run it again (not "Nothing was changed.", false after the builds). | built |
| D164 | 12.5: `.github/workflows/test.yml`: a static job (gofmt, `go vet`, the shard check), the packages other than `internal/cli` with `-race`, and `internal/cli` in four shards (`tests/tools/go-test-shard.sh`), each with and without `-tags testknobs`; `fetch-depth: 0` and tags so the two 0.2.2-tag tests run. The bats suite, the corpus and the containers stay local. | built; first run is the first push |
| D165 | 12.6: measured, 23.5 minutes for 1061 tests (34 over ten seconds; the slowest 143 s). `t.Parallel()` is not available: `newSandbox` sets `TMPDIR` for the process (`t.Setenv`), which forbids it, and the code under test reads `os.TempDir()`. Sharding (D164) is the lever; making the code take `TMPDIR` from the invocation's environment would allow parallel tests and is filed in the backlog. | built |

## 4. Gates

As the handoff: build, gofmt, `go vet`, `make lint`, Go tests, bats as the
invoking user, the diff corpus against 0.2.11, the container matrix,
`groff -k -ww`. WP 12.1 and 12.3 add tests that compare against the schema
and the tier table so a new key or verb cannot go without a completion or a
note.

## 5. Not in 0.2.12

`device config rollback` (D86, `apply-deferred.md`), NETCONF on another
Junos release (run when a second release is on the lab bench), IOS and WTI
apply, ASA, and the 0.3.0 format work.
