# tacctl 0.2.13 plan (2026-10-16)

Read `0.2.13-handoff.md` (state, working rules) first. Decisions continue
the numbering of `0.2.12-plan.md` (D159-D165). Design review: Fable,
2026-10-16.

## 1. Scope

The `internal/cli` tests run in parallel. They take 1413 s in one serial
run (789 top-level tests, 34 over ten seconds); CI cuts that by sharding
(D164). Parallel tests in one process need nothing the test sets for the
whole process, so the work is to carry what the sandbox configures to the
code through the invocation, not through the process. No state-format
change, no new device write path, no new credential.

## 2. Decisions

| # | Decision | Status |
|---|---|---|
| D166 | Option A: everything the sandbox configures reaches the code through the invocation (`Paths`, the `App`, a `hooks` value), never through the process. Not B (one shared `TMPDIR` from `TestMain`): 186 of 802 tests mutate a package variable, 152 of them through eight helpers, and they are most of the slow tests, so B would leave that tail serial. | decided |
| D167 | `paths.Paths.TempDir` is `TMPDIR` of the invocation's environment, default `os.TempDir()`; it is the only call of `os.TempDir` left. The 15 sites that read the process temp directory take it from `Paths` (`backend.Env`, `lifecycle.Env`, the TACACS renderer, `hosts.Env`, the `cli` invocation; `tier.InstallSudoers` and `CheckSudoers` take a directory argument). `store.ImportOptions.TempDir` is the precedent. A lint script fails on `os.TempDir`, `MkdirTemp("")` and `CreateTemp("")` outside `paths.go`. | decided |
| D168 | `blockEditDir` becomes `Paths.EditDir` (default `/var/tmp`); the tests point it into the sandbox. | decided |
| D169 | The hooks (`interruptSource`, `deviceDialOverride`, `newDevicePasswords`, `newLocalPasswords`, `passwordPrompt`, `factsTimeout`, `keyFallback`, `applyHoldWait`, `applyRecordFault`, `isTerminalWriter`, `editEuid`, `sshAccountOf`, `sshTerminal`, `sshConfigServer`, `newAskpassAgent`, `setNotDumpable`, `consolePolicyHook`, `terminalLine`, `devreg.ProbeDial`, `utmp.File`) are fields of a `hooks` value on the invocation; nil means the real one. `init()` overrides go. | decided |
| D170 | The sandbox helpers call `parallel(t)` (once per `*testing.T`; `TestNativePrelude` builds two sandboxes) and a serial test calls `serial(t)` first, which fails if the test already went parallel; `tparallel` and `paralleltest` are not enabled, since they want the literal call in every test. The tests that cannot be parallel stay serial and carry a `nolint` reason: the four that set the process environment (`password_cache_test.go`, `blocks_edit_test.go`) and the two that signal the test process (`TestPullInterruptBySignal`, `TestEditInterruptedRemovesTheDirectory`). They rely on Go running every serial test before the first parallel one starts, so `tparallel` and `paralleltest` are enabled to keep the serial set the annotated set. | decided |
| D171 | Upper-bound waits scale under the race detector (a `testDeadline` helper); the sleep in the break-glass race test is replaced by waiting for the prompt. Lower-bound checks stay. | not needed: the package passes under `-race -parallel 32` and shuffled |
| D172 | The applock needs no change: it is per `App`, keyed by the state directory, so sandboxes never meet. | decided |
| D173 | `TMPDIR` becomes an operator-visible setting: `man/tacctl.1` (ENVIRONMENT) and `docs/` say so, including that `sudo` may strip it. | decided |
| D174 | CI keeps `tests/tools/go-test-shard.sh` with two shards per tag set and `-race` on the shards without tags; measured here at 6-8 minutes on eight cores, to be re-measured on the runners. | decided; CI timing open |

## 3. Gates

Each WP: build, gofmt, `go vet`, `make lint`, the Man tests and the serial
`internal/cli` run green before the next starts, so a regression is
attributable. WP13.1: the three "tmp is empty" assertions still pass with the
process `TMPDIR` pointing at a directory that holds a sentinel (proof that
the code no longer reads it). WP13.2: a grep for test assignments to package
variables returns only the documented serial tests, and a serial `-race` run
is green. WP13.3, all with `-race`: `-count=3 -shuffle=on -parallel 8` three
times; `-parallel 1 -shuffle=on`; `-parallel 32` on the 8-core machine; each
serial test alone; each of these with `-tags testknobs`. At release: bats,
the diff corpus, the container matrix and the `test` workflow on the pull
request, twice in a row.
