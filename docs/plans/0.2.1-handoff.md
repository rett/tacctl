## Working rules (unchanged)

- Commits are authored as the user (their name and email, as in their earlier commits); no Claude attribution or session URLs in commit messages.
- Subagents never commit. The coordinator commits when lint and tests are green. Push only when the user asks.
- No polling loops. Never `pkill -f` or `pgrep -f` with a pattern that also appears in your own command line.
- Every test sandboxes host paths.
- No private names in repo files: no host names, addresses, user names, home paths or domains. Use "the dev server", "the test client", "the production host", `example.*`. `make lint` runs `tests/tools/no-private.sh`. In a cloud session the untracked private-patterns file (`~/.config/tacctl/private-patterns`) is absent, so only the generic checks run; be careful by hand.
- Never anything against the production host. Live tests (WP7.4, and checking the UID renumber on the dev server and test client) need the user's own machine. A cloud session cannot reach those hosts or run the rootless-podman containers. Do code, unit, bats and docs work there; leave live and container runs for a local session.
- Live-test reminder for the renumber: the first sync renumbers the dev server's map (it keeps a `.pre-renumber-*` copy) and the hosts' accounts. A user logged in during that sync is skipped and retried later.
