# tacctl 0.2.18 plan: verb names that complete

0.2.18 is a small release on top of 0.2.17. A verb that is a complete word
and also the prefix of a sibling cannot be completed with Tab: after
`device config` the shell does not add the space, because the word might
still become `config-syntax`. The release renames the siblings, makes the
completion of a vendor-specific setting offer only the devices it can be
set on, and gives an unknown command a short error.

Decisions D273-D277; work packages WP18.1 to WP18.4 (WP18.5 is the
release).

## Decisions

- **D273.** `device config-syntax` becomes `device ios-syntax`. The flag
  `--config-syntax` becomes `--ios-syntax` (`device add`, the `--apply`
  text and every place that names it). The registry field keeps the name
  `config-syntax` (existing registries load unchanged), and so does the
  `field=` value of the `device set` audit line. Every message, usage line
  and walkthrough comment names the new verb.
- **D274.** `device notices [<name>] [--all]` becomes
  `device notice list [<name>] [--all]`. `device notice <name> ack|unack
  <kind>` stays; the two forms are told apart by their argument count (a
  device named `list` still works with `ack` and `unack`).
- **D275.** `device ssh-config` becomes `device client-config` (same
  output, same tier). `ssh` is then not a prefix of another `device` verb.
- **D276.** Name completion can be limited to one vendor: `ios-syntax`
  offers the Cisco devices, `netconf` the Junos devices. What a typed name
  is checked against does not change (a non-Cisco device is still refused
  with the Cisco-setting message; `auto` still clears a stale value).
- **D277.** An unknown top-level command prints one error line naming the
  word, a suggestion when the word is a verb of a command (`enroll` ->
  `device enroll`, `host enroll`), and a pointer to `tacctl` for the list,
  not the whole help. The exit status stays 1.
- **No legacy names.** The old verbs and the old flag are gone, not
  aliased: they are an unknown verb or flag like any other. `rollback`
  to 0.2.17 converts the sudoers drop-in, which then carries the rules
  the older binary needs.

## Work packages

- **WP18.1.** `ios-syntax` (D273), with the tier and sudoers rows, the
  rollback table, the docs, the man page, the tests.
- **WP18.2.** `notice list` and `client-config` (D274, D275), the same
  way.
- **WP18.3.** Vendor-limited completion (D276) and the unknown-command
  error (D277).
- **WP18.3b.** An audit of Tab completion and `?` output at every
  position of every verb (alignment, wording, punctuation, missing or
  placeholder descriptions, tier lines), with the defects fixed and the
  output pinned by tests.
- **WP18.4.** CHANGELOG, release notes, the backlog, this plan's status.
- **WP18.5.** The release gates and the release.
