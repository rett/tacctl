# tacctl 0.2.5: execution breakdown (2026-10-10, re-scoped the same day)

The work packages of `0.2.5-plan.md` (decisions D94-D105, the paste-ready output), for a coordinator to hand to subagents. The deferred apply packages (WP12.x) are in `apply-deferred.md` Part B. Rules: subagents work in worktrees off the branch tip and never commit; no two packages that run in parallel own the same file; every package ends with its own acceptance checks green; the coordinator reviews, merges, renumbers CHANGELOG items, regenerates shared goldens once per merge and commits on request. Model routing: Opus reviews, Sonnet and Haiku implement, Fable decides design. The 0.2.4 safety posture for live work applies unchanged (below).

Sizes: S ≈ ½ session, M ≈ 1 session, L ≈ 1½-2.

## Acceptance commands (from `CLAUDE.md`; every package runs the ones that apply)

```
make build
LANG=C.UTF-8 go test ./internal/...                      # internal/cli: setsid -w ... < /dev/null, a scratch GOCACHE

tests/containers/hosts/run.sh ubuntu-noble tacplus       # once, after WP13.2 (the sudoers drop-ins change)
```

### WP13.1 `internal/devconf/plan` (Sonnet, Opus review, offline)

- **Owns:** `internal/devconf/plan/**`, `tests/fixtures/golden/plan.*`.
- **Interfaces (plan §5):** `Plan`, `Options`, `Delta`, `Line`, `Display`, `Equal`, `Needs`, `Block`, `Plain`, the JSON shape; the ownership tables of plan §4 as data (`owned.go`) with one test per row; the in-memory editor (`simulate.go`) and the property test; imports `devconf.Extracted`, `devices.Section`, `devconf.Compare` (the delta is computed from the comparison's `-`/`+`/`!` lines, not from the raw text).

- **Acceptance:** `go test -race ./internal/devconf/plan`, `make lint`.

## Safety posture for the live packages

- The lab switch: read-only by default; a load only in `configure private`, ended with `rollback 0` and `exit`; `zz-tacctl-*` names for anything created; **no commit of any kind in this release's live work** (the user's go-ahead covers private loads only; a commit, if ever wanted for L3, is asked for separately); `gotest*` accounts only; the dev server is the only AAA server the test logins use; never the production host or a production device.
- Run sheets, addresses and names stay outside the repo; fixtures are sanitised before they enter it.
- No lab router: Cisco blocks are marked not lab-tested and nothing Cisco is tested live.
