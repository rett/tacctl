## L1 texts

- Operational prompt `admin@lab-sw1> `, preceded by a `{master:0}` line on a
  virtual chassis (blank line before it). Configure prompt `admin@lab-sw1# `,
  preceded by `{master:0}[edit]` (or `[edit system login]`). A standalone
  device prints no `{master:N}` line.
- `configure` echoes `configure `, prints `Entering configuration mode`, a
  blank line and the location line. `exit` prints `Exiting configuration
  mode`.
- `configure exclusive`: `warning: uncommitted changes will be discarded on
  exit` then the entering text. Refused while another session holds it:
  `error: configuration database locked by:` + `  admin terminal pts/0 (pid
  84557) on since 2026-10-13 20:02:28 AKDT` + `      exclusive
  {master:0}[edit]`.
- `configure` (shared) while exclusive is held: enters, with `Users
  currently editing the configuration:` and the holder's line. `configure
  private` while exclusive is held: `warning: changes cannot be committed
  while 'configure exclusive' is active`.
- `commit check`: `configuration check succeeds`.
- `commit confirmed N comment "..."`: `configuration check succeeds`,
  `commit confirmed will be automatically rolled back in N minutes unless
  confirmed` (`1 minutes` for N=1), `commit complete`, then the banner line
  and the location line.
- `rollback 1` prints `load complete`; `commit` after it prints
  `configuration check succeeds` and `commit complete` and removes the banner.
- `commit` with no private changes in a private session: `warning: no
  private changes to commit`.
- A space in a line typed at the configure prompt triggers completion on a
  pty; commands are sent without terminal editing games (the transport sends
  whole lines; the spike's `run show system rollback compare` failure was
  that command not existing).
