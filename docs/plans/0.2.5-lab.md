# 0.2.5 lab check results (2026-10-10)

What the Junos lab check of `0.2.5-plan.md` section 8 found on the lab switch
(Junos 25.4R1-S2.3). Every load was in a private session or a shared edit
session that was rolled back; nothing was committed; the configuration was
compared with its pre-check text at the end of each item (empty `show
configuration | compare rollback 0`, `show system users` empty). Objects were
named `zz-tacctl-*`; the engineer login was a `gotest*` account on the test
server, removed afterwards. The router items are in `0.2.4-spike.md`
("Legacy IOS 12.4") and the committed fixture
`tests/fixtures/devconf/ios/real-12.4-7200/`.

## ITP 2800 images (item I1)

The version and ssh output of an ITP image on a 2800-series router:

```
<host>#show version | include Version
Cisco IOS Software, 2800 Software (C2800NM-ITPK9-M), Version 12.4(15)SW4, RELEASE SOFTWARE (fc1)
ROM: System Bootstrap, Version 12.4(13r)T11, RELEASE SOFTWARE (fc1)
<host>#show ip ssh
SSH Enabled - version 2.0
Authentication timeout: 120 secs; Authentication retries: 3
```

| Point | Result |
|---|---|
| Image and train | `C2800NM-ITPK9-M`, IOS 12.4(15)SW4: the same train as the lab 7200 emulator (`C7200-ITPK9-M` 12.4(15)SW), so the lab router's findings (ssh offers, stored forms, `privilege` behaviour, timed replace in seconds, the lock-outs) apply |
| Version line | `Cisco IOS Software, <platform> Software (<image>), Version 12.4(15)SW4, RELEASE SOFTWARE (fc1)`: starts `Cisco IOS Software,` and holds `Version 12.`, so D113's derivation reads it as `ios12` (D114's `IOS (tm)` older shape stays [A], for 12.2 images) |
| ssh | protocol 2.0 (no ssh version 1 on such a unit). `show ip ssh` on 12.4 prints no algorithm lines, so the offered key exchanges and ciphers are not in the output; the lab 7200 at the same train offers `diffie-hellman-group1-sha1`, `ssh-rsa` and CBC ciphers, which the legacy-ssh profile covers; a `3des-cbc`-only image is still [A] |
| Open | the algorithm offers of a 2800 itself (one `ssh -vv` line would settle it); the `IOS (tm)` 12.2 line shape on an image that runs 12.2 |
