# 0.2.5 lab check results (2026-10-10)

What the Junos lab check of `0.2.5-plan.md` section 8 found on the lab switch
(Junos 25.4R1-S2.3). Every load was in a private session or a shared edit
session that was rolled back; nothing was committed; the configuration was
compared with its pre-check text at the end of each item (empty `show
configuration | compare rollback 0`, `show system users` empty). Objects were
named `zz-tacctl-*`; the engineer login was a `gotest*` account on the test
server, removed afterwards. The router items are in `0.2.4-spike.md`
("Legacy IOS 12.4") and the committed fixture
`tests/fixtures/devconf/ios/real-12.4-7200/`.
