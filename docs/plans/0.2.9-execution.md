# tacctl 0.2.9: execution breakdown (2026-10-13)

The work packages of `0.2.9-rollout-plan.md` (D128-D144) and
`0.2.9-conversion.md`, for a coordinator to hand to subagents. Rules:
subagents work in worktrees off the branch tip and never commit; no two
packages that run in parallel own the same file; every package ends with
its own acceptance checks green; the coordinator reviews, merges,
renumbers CHANGELOG items, regenerates shared goldens once per merge and
commits on request. Model routing: Opus reviews, Sonnet and Haiku
implement, Fable decides design. Package numbers continue the project's:
**WP14.0-14.13** (0.2.5 used WP13.x; the 0.2.7 blocks plan used B1-B9).
`feature/0.2.9` starts from `develop` after 0.2.8 is merged (WP14.3 and
WP14.6 consume 0.2.8's facts and gate table, D144).

Sizes: S ≈ ½ session, M ≈ 1 session, L ≈ 1½-2. **Total ≈ 14-18
sessions, ≈ 9,000-12,000 lines with tests**; the cut order is plan §11.

## Acceptance commands (`CLAUDE.md`; every package runs the ones that apply)

```
make build
LANG=C.UTF-8 go test ./internal/...        # internal/cli: setsid -w ... < /dev/null, a scratch GOCACHE
make lint GOLANGCI_LINT=<path>             # includes tests/tools/no-private.sh and the man tests
make man                                   # then check the generated blocks are what the code says
tests/bats/bats-core/bin/bats tests/integration/<file>.bats    # as user tester, after make build
tests/diff/run.sh --all --against 0.2.8    # every difference @known 0.2.9 item N
tests/containers/hosts/run.sh ubuntu-noble tacplus   # once, after WP14.6 (the sudoers drop-ins change)
```

### WP14.1 `internal/devssh` (Sonnet, Opus review, offline)

- **Owns:** `internal/devssh/cli.go` (the Junos profile's configure prompt,
  the `[edit...]` line as output, the `WithCommand` option on `openShell`:
  `sess.Start(cmd)` instead of `sess.Shell()`), `devssh.go`
  (`Client.LocalAddr()`), `errors.go` (the algorithm-mismatch
  classification), a `Commands()` log on the shell session, tests.

### WP14.4 `internal/devrollout` (Sonnet, Opus safety review, offline)

- **Owns:** `internal/devrollout/**`.
- **Interfaces:** plan §5 (`Transport`, `JunosCLI`, `Driver`, `Input`,
  `Outcome`, the error table, the shape store, the lock); the texts from
  14.0 (placeholders [A] until then, each with the fallback of plan §9).
- **Constraint:** no terminal, no logging, no global state; the clock, the
  random source and the password sources are injected; the driver never
  confirms from any session but the one that committed; every exit of
  plan §3.2 is a named result with a test; the command log of a run is
  asserted to hold nothing but the delta's statements and the wrapper
  words; nothing a transport prints or stores holds a secret value (the
  caller elides before `Run`; a test scans the log).
- **Review focus (Opus):** can any path leave a confirmed commit pending
  with the job returned and the record not saying `pending`; can any path
  write outside the delta; is `Discard` typed on every failure before the
  commit; is the state read before it is named after a failed commit
  text; is a refused fresh login distinguishable from a rejected password.
- **Acceptance:** `go test -race ./internal/devrollout`, `make lint`.
