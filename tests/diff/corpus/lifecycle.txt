# tacctl backend enable|disable, install and uninstall (WP4.3): the paths that
# stop before they change anything, which are the only ones a sandboxed run may
# take. install and uninstall stop at their confirmation prompt (a closed stdin
# or 'n' is a no); anything past it would install packages, write /opt, /etc
# and /usr/local or remove them. Never add -y|--yes to these lines, nor a 'y'
# answer.
#
# Left out on purpose:
#   upgrade        its first steps (the backends' upgrade preflight, then
#                  'git config --system' for the deploy clone) touch the host
#                  before any prompt; it is covered by internal/lifecycle's
#                  tests, the lifecycle bats files (TACCTL_TEST_ROOT) and the
#                  container cross-over rehearsal (tests/containers/crossover).
#   config branch  it reads and fetches the deploy clone /opt/tacctl, which
#                  no variable moves for the bash release; it is covered by
#                  characterisation.bats (six tests, on a scratch clone).
#   backend enable radius with a yes: it installs FreeRADIUS.
# Run: tests/diff/run.sh lifecycle
